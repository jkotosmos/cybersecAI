# VibeSec

Платформа автоматизированного **этичного** тестирования безопасности веб-приложений.
Для белых хакеров и исследователей: официальные bug bounty программы, собственные
или разрешённые проекты (включая приложения, собранные AI-генераторами кода).

> ⚠️ Только авторизованные цели. Перед каждым запуском пользователь обязан
> подтвердить право на тестирование. Проверка ограничена подтверждённым scope.

## Что умеет (каркас)

- Выбор модуля проверки большими карточками в GUI.
- Запуск одной кнопкой — дальше всё автономно.
- Живой вывод инструментов в реальном времени (subprocess → WebSocket → терминал).
- Прогресс-бар, статусы этапов, остановка в любой момент.

## Модули

| Модуль | Назначение |
|--------|-----------|
| Быстрая разведка | Поддомены, живые хосты, порты, технологии |
| Полный анализ поверхности | Обход контента, сбор эндпоинтов, карта поверхности |
| Типовые проблемы безопасности | Проверка по шаблонам, верификация, приоритизация |
| Проверка AI-кода (vibe-coding) | Секреты, небезопасные дефолты, зависимости |
| Комплексная проверка | Полный цикл всех этапов |
| Генерация отчёта | Сборка результатов в отчёт для bug bounty |

## Архитектура

```
GUI (фронтенд)  ──WebSocket──▶  FastAPI backend  ──subprocess──▶  CLI-инструменты
   карточки,                     Orchestrator                      (subfinder, httpx,
   терминал,                     ├─ scope (барьер)                  nuclei, gitleaks, …)
   прогресс                      ├─ runner (стриминг stdout/stderr)
                                 └─ agents (этапы модуля)
```

- **`backend/app/core/orchestrator.py`** — последовательность этапов и агентов.
- **`backend/app/core/runner.py`** — запуск инструмента, построчный стриминг, остановка (SIGTERM всей process group).
- **`backend/app/core/scope.py`** — обязательная проверка цели перед запуском.
- **`backend/app/agents/*.py`** — агенты; один агент = набор шагов (этапов).
- **`backend/app/modules/registry.py`** — связь кнопок GUI с пайплайнами агентов.

Если инструмент не установлен, шаг показывает демо-вывод — каркас работает «из коробки»,
а реальные инструменты подключаются по мере установки.

## Запуск (Linux)

```bash
./run.sh
# открой http://127.0.0.1:8787
```

Вручную:

```bash
cd backend
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8787
```

## Протокол WebSocket (`/ws/run`)

```jsonc
// клиент → сервер
{"action": "start", "module": "recon", "target": "example.com", "scope_confirmed": true}
{"action": "stop"}

// сервер → клиент (поток событий)
{"type": "status",   "state": "running|stopped|done", "message": "..."}
{"type": "stage",    "index": 0, "name": "...", "state": "start|done", "total": 4}
{"type": "log",      "stage": "...", "stream": "stdout|stderr|system", "line": "..."}
{"type": "progress", "value": 42}
{"type": "done",     "summary": "..."}
{"type": "error",    "message": "..."}
```

## Статус

Рабочий каркас: backend + оркестратор + стриминг + функциональный фронтенд-клиент.
Дальше: полноценный GUI (SvelteKit / Tauri) на основе дизайн-прототипа, реальные
обёртки инструментов, постоянный allowlist scope и генерация отчётов.
